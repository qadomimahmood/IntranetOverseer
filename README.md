# Intranet Overseer

Intranet Overseer is a bilingual building management system for tracking studio rentals, payments, and expenses. It features a real-time dashboard, floor-by-floor unit oversight, and role-based access for owners and guards, simplifying property financial operations in English and Arabic.

## Features

- **Dashboard**: Real-time financial and occupancy overview.
- **Studio Management**: Track status across multiple floors.
- **Payments**: Record subscription payments and track debts.
- **Expenses**: Log maintenance and operational costs.
- **Bilingual**: Full English and Arabic support.

## Getting Started

1.  Clone the repository:
    ```bash
    git clone https://github.com/qadomimahmood/IntranetOverseer.git
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```
